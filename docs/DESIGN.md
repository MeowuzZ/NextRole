# UI 设计规则

基于配色、布局留白、字体层级、形状比例、材质光影和反馈六个维度整理。参考图片用于设计方法，产品延续已经确认的明亮玻璃风格，保留数据、模块关联、操作入口和填写逻辑。

## 配色

- 页面底色浅蓝灰，主要阅读面为白色。
- 主要文字深蓝灰；辅助文字保持可读对比度，不使用过浅的灰字。
- 蓝色用于主操作、选中与焦点；红色用于移入回收站等危险操作。
- 玻璃效果集中于外框和导航，表格正文、简历与表单不叠加大面积模糊。

## 结构与间距

- 采用 8px 基础间距，常用 8 / 16 / 24px。
- 标题、视图工具和业务操作分层；总表数据仍为页面主体。
- 桌面内容宽度有上限，长表提供内部滚动、固定表头和固定序号列。
- 手机保留单列表单、底部导航和独立滚动区。

## 字体与控件

- 页面标题约 26px，区块标题 14–16px，正文 13–14px，辅助文字 11–12px。
- 主按钮、次按钮、页签、菜单项和危险图标均有明确的圆角矩形触控区。
- 常规控件高 38–42px，移动端延续较大的触控尺寸。
- 卡片圆角 16px，控件约 10px；边框与阴影使用共享变量。

## 反馈

- 悬停强调边框和背景；点击使用轻微缩放；焦点保留清晰轮廓。
- 选中项使用浅蓝底和蓝色文字，危险操作为红色且保留文字提示与无障碍名称。
- 动画不改变内容布局，尊重减少动态效果偏好；循环滚轮选框保持固定。
